# CHANGELOG

We follow [Semantic versioning](https://semver.org/) in the code. And in this file you can find detailed info about changes we made version to version.

Each released version should be documented in this file with some details regarding what has changed which are
 * Bugfixes
 * New features
 * or Breaking changes

Then 
 * Each section has a list of entries. Please keep the entries shot and concise!
 * If you have related JIRA ticket(s) make sure in your entry they are quoted in!
 * **Note:** obviously a release entry (version) also clearly suggests which sub-sections (breaking / new / bugfix) should you expect under specific versions... ;-)
